Tugas: Buatlah sebuah aplikasi sederhana berbasis PHP yang memanfaatkan beberapa fungsi (function) buatan sendiri.

Ketentuan:

1. Minimal menggunakan 3 fungsi buatan sendiri.
	- Setiap fungsi harus memiliki peran yang jelas.
	- Fungsi dapat berupa fungsi dengan parameter dan return value.

2. Contoh ide aplikasi (pilih salah satu atau kembangkan sendiri):
	- Kalkulator sederhana (penjumlahan, pengurangan, diskon, konversi suhu, konversi mata uang).
	- Aplikasi pengelola produk toko (hitung harga setelah diskon, pajak, total belanja).

3. Gunakan form HTML sederhana untuk input data.

4. Hasil aplikasi harus ditampilkan secara dinamis setelah form dikirim.

5. Struktur kode rapi dan tambahkan komentar untuk menjelaskan bagian penting.

6. File dikumpulkan dalam format ZIP berisi:
	- File .php (source code)
	- Screenshot hasil aplikasi

Catatan: Pastikan setiap fungsi jelas tugasnya dan gunakan nama fungsi yang deskriptif.
