## 🧠 Learning Journey (Apa yang Saya Pelajari)

Semester ini memberikan kurva pembelajaran yang sangat curam namun luar biasa berharga, terbagi dalam tiga jalur utama:

### 🔬 Jalur Praktikum (Fundamental & Logic)
Fokus pada penguasaan fundamental web tanpa bergantung pada alat *magic*.
* **Version Control & Deployment:** Memulai perjalanan dari eksekusi Git murni. Berbeda dengan panduan silabus yang menggunakan *Git GUI Desktop*, saya secara sadar dan konsisten mengeksekusi siklus *git add-commit-push* murni melalui *Terminal* demi memperkuat fundamental CLI. Berawal dari peluncuran situs statis "Hello World" sederhana via GitHub Pages, repositori ini kini telah berevolusi menjadi *Single Page Application* yang kompleks.
* **Semantic HTML & CSS Mastery:** Menerapkan struktur *Semantic HTML* (penggunaan *tag* spesifik seperti `<main>`, `<section>`, `<article>`) untuk aksesibilitas dan SEO yang baik, serta merakit UI responsif yang *pixel-perfect* menggunakan CSS murni tanpa *framework* yang memberatkan.
* **JavaScript Fundamental:** Menguasai manipulasi DOM (*Document Object Model*), *Event Handling*, dan logika pemrograman dinamis pada sisi klien menggunakan *Vanilla JavaScript* murni.
* **Native PHP & Package Management:** Memahami logika *Backend* paling dasar, eksekusi kueri SQL dengan MySQL, dan membangun sistem CRUD dari nol. Pada fase pasca-UTS, materi berkembang dengan mengadopsi **Composer** untuk menginstal dan mengimplementasikan pustaka eksternal (*third-party libraries*) langsung ke dalam ekosistem PHP murni.

### 📚 Jalur Teori (CMS & Modern Framework)
Fokus pada evolusi arsitektur perangkat lunak dari platform *monolithic* tradisional ke *framework* tingkat industri.
* **CMS & Server Management (Pra-UTS):** Pengenalan manajemen *hosting* cPanel (InfinityFree) dan pembangunan *website* instan menggunakan WordPress & Elementor.
* **Laravel Ecosystem (Pasca-UTS):** Pengenalan *package manager* (Composer), pemahaman pola arsitektur MVC, *Routing*, dan *Eloquent ORM*.
* **Modern SaaS Architecture:** Bergeser dari PHP tradisional menuju ekosistem React 19 dan Next.js 16 (App Router) dengan Prisma ORM untuk membangun *Hyperlocal Marketplace*.

### 🤖 Eksplorasi Mandiri: Terminal-First AI Engineering
Alih-alih mematuhi silabus untuk menggunakan ekstensi AI berbasis GUI di VSCode (seperti *9router*, *opencode*, dan *kilocode*), saya memilih rute yang lebih radikal dan menantang:
* **Integrasi Lintas Mata Kuliah:** Bermigrasi penuh ke **Antigravity CLI** dan **Opencode CLI** di *terminal*. Rute ini selaras dengan keputusan awal saya menggunakan Git CLI, secara sengaja dipilih untuk memadukan rutinitas *coding* dengan teori dari kelas **Sistem Operasi**, **Jaringan Komputer**, dan **Administrasi Jaringan**. Meski sempat kesulitan menyerap teori di kelas, rutinitas *command-line* harian ini sukses membangun *muscle memory* yang terbukti ampuh—pasca-UAS, saya berhasil men-*setup Virtual Machine Linux Server* secara mandiri di **Microsoft Azure** ([fathur.duckdns.org](http://fathur.duckdns.org)).
* **Architectural Leadership:** Bertransisi dari sekadar "pengetik kode" menjadi seorang *Architect* yang memvalidasi *output* probabilitas AI dan mengatur pagar pembatas (*guardrails*) menggunakan instruksi sistem (`AGENTS.md`).
