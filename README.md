## 🧠 Learning Journey (Apa yang Saya Pelajari)

Semester ini memberikan kurva pembelajaran yang sangat curam namun luar biasa berharga, terbagi dalam tiga jalur utama:

### 🔬 Jalur Praktikum (Fundamental & Logic)

Fokus pada penguasaan fundamental web tanpa bergantung pada alat _magic_.

- **Version Control & Deployment:** Memulai perjalanan dari eksekusi Git murni. Berbeda dengan panduan silabus yang menggunakan _Git GUI Desktop_, saya secara sadar dan konsisten mengeksekusi siklus _git add-commit-push_ murni melalui _Terminal_ demi memperkuat fundamental CLI. Berawal dari peluncuran situs statis "Hello World" sederhana via GitHub Pages, repositori ini kini telah berevolusi menjadi _Single Page Application_ yang kompleks.
- **Semantic HTML & CSS Mastery:** Menerapkan struktur _Semantic HTML_ (penggunaan _tag_ spesifik seperti `<main>`, `<section>`, `<article>`) untuk aksesibilitas dan SEO yang baik, serta merakit UI responsif yang _pixel-perfect_ menggunakan CSS murni tanpa _framework_ yang memberatkan.
- **JavaScript Fundamental:** Menguasai manipulasi DOM (_Document Object Model_), _Event Handling_, dan logika pemrograman dinamis pada sisi klien menggunakan _Vanilla JavaScript_ murni.
- **Native PHP & Package Management:** Memahami logika _Backend_ paling dasar, eksekusi kueri SQL dengan MySQL, dan membangun sistem CRUD dari nol. Pada fase pasca-UTS, materi berkembang dengan mengadopsi **Composer** untuk menginstal dan mengimplementasikan pustaka eksternal (_third-party libraries_) langsung ke dalam ekosistem PHP murni.

### 📚 Jalur Teori (CMS & Modern Framework)

Fokus pada evolusi arsitektur perangkat lunak dari platform _monolithic_ tradisional ke _framework_ tingkat industri.

- **CMS & Server Management (Pra-UTS):** Pengenalan manajemen _hosting_ cPanel (InfinityFree) dan pembangunan _website_ instan menggunakan WordPress & Elementor.
- **Laravel Ecosystem (Pasca-UTS):** Pengenalan _package manager_ (Composer), pemahaman pola arsitektur MVC, _Routing_, dan _Eloquent ORM_.
- **Modern SaaS Architecture:** Bergeser dari PHP tradisional menuju ekosistem React 19 dan Next.js 16 (App Router) dengan Prisma ORM untuk membangun _Hyperlocal Marketplace_.

### 🤖 Eksplorasi Mandiri: Terminal-First AI Engineering

Alih-alih mematuhi silabus untuk menggunakan ekstensi AI berbasis GUI di VSCode (seperti _9router_, _opencode_, dan _kilocode_), saya memilih rute yang lebih radikal dan menantang:

- **Integrasi Lintas Mata Kuliah:** Bermigrasi penuh ke **Antigravity CLI** dan **Opencode CLI** di _terminal_. Rute ini selaras dengan keputusan awal saya menggunakan Git CLI, secara sengaja dipilih untuk memadukan rutinitas _coding_ dengan teori dari kelas **Sistem Operasi**, **Jaringan Komputer**, dan **Administrasi Jaringan**. Meski sempat kesulitan menyerap teori di kelas, rutinitas _command-line_ harian ini sukses membangun _muscle memory_ yang terbukti ampuh—pasca-UAS, saya berhasil men-_setup Virtual Machine Linux Server_ secara mandiri di **Microsoft Azure** ([fathur.duckdns.org](http://fathur.duckdns.org)).
- **Architectural Leadership:** Bertransisi dari sekadar "pengetik kode" menjadi seorang _Architect_ yang memvalidasi _output_ probabilitas AI dan mengatur pagar pembatas (_guardrails_) menggunakan instruksi sistem (`AGENTS.md`).
